# Перенос проекта в новый репозиторий и передача контекста

## Цель
Новый репозиторий должен быть отдельным проектом с собственным чатом, деплоем и настройками.

## Что делать

### 1. Создать новый GitHub репозиторий
- Открыть GitHub
- Нажать New repository
- Выбрать название, например: `interpain_b24forms` или `painhelp-site`
- Выбрать Public/Private
- Создать репозиторий

### 2. Подключить текущий проект к новому репозиторию
В терминале:

```bash
cd /Users/kovalevroman/Code/painhelp
git remote rename origin old-origin
git remote add origin git@github.com:твой-логин/название-репозитория.git
git push -u origin main
```

### 3. Проверить, что всё ушло в новый репозиторий
Проверить:

```bash
git remote -v
git status
git log --oneline -5
```

### 4. Подключить новый репозиторий к Vercel
- Открыть Vercel
- Выбрать Add New Project
- Подключить новый GitHub репозиторий
- Запустить деплой

### 5. Добавить переменные окружения
Для проекта с Bitrix webhook нужно добавить:

```text
BITRIX_WEBHOOK=your_webhook_url
```

### 6. Для каждого проекта вести отдельный чат
Лучше иметь:
- отдельный репозиторий = отдельный проект
- отдельный чат = отдельный контекст

Это помогает не смешивать задачи и не засорять один разговор.

## Важные замечания
- Не нужно заново настраивать работу с AI/assistant в коде.
- Нужно заново подключить только:
  - новый GitHub repo
  - новый Vercel проект
  - env variables

## Короткая схема
1. Создать новый repo
2. Подключить проект к нему
3. Запушить код
4. Подключить к Vercel
5. Добавить `BITRIX_WEBHOOK`
6. Продолжать работу в отдельном чате под этот проект
